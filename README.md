# 🚀 AI Powered Human Resource Management System (HRMS)

## 📌 Overview

AI Powered HRMS is a next-generation Human Resource Management System designed to automate recruitment and HR operations using Artificial Intelligence.

The platform combines AI-driven resume screening, AI interview evaluation, candidate ranking, employee management, attendance tracking, payroll management, and performance monitoring into a single unified solution.

---

## 🎯 Problem Statement

Traditional HR processes are often:

- Time-consuming
- Manually intensive
- Prone to bias
- Difficult to scale

Our solution leverages AI to streamline recruitment and HR operations while maintaining human decision-making where necessary.
